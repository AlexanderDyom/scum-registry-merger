# Third-party notices

SCUM Registry Merger links against the following open-source packages (versions in the `.csproj` files). Each keeps its
own licence; no source code from these projects is copied into this repository.

| Package | Purpose | Licence |
|---|---|---|
| [CUE4Parse](https://github.com/FabianFG/CUE4Parse) 1.2.2 | reading Unreal Engine pak files (the game's and the mods') | Apache-2.0 |
| [ScumModKit](https://github.com/AlexanderDyom/scum-modkit) (git submodule `external/modkit`) | reading and writing cooked packages (the shared cooking files) | MIT |
| [System.IO.Hashing](https://github.com/dotnet/runtime) 8.0.0 | used by ScumModKit | MIT |
| [System.Security.Cryptography.ProtectedData](https://github.com/dotnet/runtime) 8.0.0 | Windows DPAPI, to store the AES key encrypted for the current user | MIT |
| [.NET 8 runtime and WPF](https://github.com/dotnet) | runtime and window UI, bundled in the self-contained executables | MIT |

Transitive dependencies of CUE4Parse (Newtonsoft.Json, K4os LZ4, ZstdSharp, Oodle.NET, Zlib-ng.NET, BouncyCastle,
Serilog, Blake3, LZMA-SDK) keep their respective licences (MIT / Apache-2.0 / BSD).

## References (no code taken)

- [SCUM Modding Studio](https://github.com/ALLAWI32/SCUM-Modding-Studio) (MIT, Copyright (c) 2026 ALLAWI and
  contributors). Its `AssetRegistryFile` documents the cooked AssetRegistry layout; `Core/AssetRegistry.cs` is a separate
  implementation of the same file format.
- [repak](https://github.com/trumank/repak) (MIT / Apache-2.0). `Core/PakWriter.cs` writes the same pak v11 layout and
  was checked against repak's output; no repak code is included.
- The pak priority rules in `Core/PakPriority.cs` follow Unreal Engine 4.27's documented behaviour and were confirmed
  from the game's own log; no Unreal Engine source code is included.

## Fonts and icons

No font files are bundled. The window uses Bahnschrift and Segoe Fluent Icons / Segoe MDL2 Assets, which come with
Windows. The program icons are original pixel art generated by `icons/make_icon.ps1`.

## Game files

SCUM and its assets are the property of Gamepires / Jagex. This tool reads the user's own installed game files and
never redistributes them; the game's pak AES key is never stored in this repository or in the releases. The shared
registry pak it writes is created only on the user's own computer, from that user's installed game and mods; the
releases contain no game files. A game version reference (`make-reference`) is made by the user on their own computer,
holds only 64-bit hashes of record names (no game file names or content) and is never published by this project. This
project is not affiliated with Gamepires or Jagex.
